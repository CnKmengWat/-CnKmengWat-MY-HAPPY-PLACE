# LoveTalk — Starter App

នេះជាគម្រោងដំបូងរបស់ LoveTalk សម្រាប់ Android និង iPhone ដោយប្រើ Expo + React Native។

## អ្វីដែលមានក្នុងកំណែនេះ
- Home / Discover / Match / Messages / Profile
- Party tab: daily events, matching events, gifts/rewards, ranking, missions and countdown-style event cards
- Voice Room preview
- រចនាប័ទ្ម dark purple + pink
- Navigation រវាងទំព័រ
- ទិន្នន័យមិត្តភក្តិគំរូ (មិនមែនអ្នកប្រើពិត)

## របៀបបើកសាកល្បង
1. ដំឡើង Node.js លើកុំព្យូទ័រ។
2. Extract ZIP នេះ។
3. បើក Terminal នៅក្នុង folder `LoveTalk_Starter`។
4. រត់៖
   ```bash
   npm install
   npx expo start
   ```
5. ដំឡើងកម្មវិធី Expo Go លើទូរស័ព្ទ ហើយស្កេន QR code។

## ចំណាំសំខាន់
នេះជាគំរូ UI ដែលអាចបើកសាកល្បងបាន មិនទាន់ជាប្រព័ន្ធ Social App ពេញលេញទេ។ មុនដាក់ឱ្យអ្នកប្រើប្រាស់ពិត ត្រូវបន្ថែម៖
- ចុះឈ្មោះ / ចូលគណនី (Authentication)
- Database និងរូបថត profile
- Real-time chat និង push notifications
- Matching service
- Voice/video calling service
- Block, report, moderation និង privacy controls
- ការធ្វើតេស្ត និងរៀបចំការបោះពុម្ពផ្សាយ App Store / Google Play

កុំដាក់ API keys ឬ passwords ក្នុង source code ដែលចែករំលែកជាសាធារណៈ។
